# Ticket Preview App

Mini proyecto separado para mostrar el ticket/factura fuera del POS principal.

## Uso

```bash
cd ticket-preview-app
npm run dev
```

Abre `http://localhost:4174`.

## Qué incluye

- Visualización del ticket duplicada del proyecto principal
- Lógica de IVA, descuento y cambio en TypeScript
- Mock DB con `localStorage` para estabilizar la demo
- Configuración editable del negocio y formato de papel
