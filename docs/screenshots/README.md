# Capturas del proyecto

Coloca aquí las imágenes que quieras mostrar en el `README.md` de la raíz.

| Archivo sugerido | Contenido |
|------------------|-----------|
| `login.png` o `login.svg` | Pantalla de inicio de sesión |
| `dashboard.png` o `dashboard.svg` | Panel principal post-login |
| `pos.png` o `pos.svg` | Punto de venta |

Puedes usar **PNG** o **SVG**. Si añades un PNG, actualiza la ruta en el README (por ejemplo `login.png` en lugar de `login.svg`).

Rutas relativas desde la raíz del repo: `docs/screenshots/<archivo>`.
